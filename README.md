# Marketing assets (public CDN)

Public image host for social-media cards. Buffer fetches post images **server-side** from a
public `https://` URL, so these files must be publicly reachable — that is the entire purpose
of this repository.

## What is here

Rendered social cards only. Generated by
`~/.hermes/profiles/marketer/automation/{cardgen,carousel}.py`.

```
misomind/    Instagram carousel slides, 1080x1350 PNG
```

Files are named `<post-id>-<slide>.png` (e.g. `c001-1.png`), matching the entry ids in each app's
`marketing/automation/content-bank.json`.

## What must never be here

- No source code
- No API keys, service-account JSON, keystores or `.env` files
- No screen recordings or unreleased product footage
- Nothing that is not a rendered marketing image intended for public posting

Everything in this repo is world-readable by design. Treat it as a publishing surface, not storage.

## URL pattern

```
https://<user>.github.io/marketing-assets/misomind/c001-1.png
```

Set that base as `MEDIA_BASE` for `queue_runner.py`.
